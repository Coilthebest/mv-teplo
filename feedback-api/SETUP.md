# Состояние отзывов Teplo

Опубликовано 24 ноября 2026.

- Отзывы и предложения отделены от вопросов; вопросы открываются по нажатию.
- Для отправки обязательны email и подтверждение письмом через Yandex Cloud Postbox.
- На сайте email частично скрывается тремя звёздочками.
- Для отзывов доступны 1–5 звёзд; средняя оценка считается только по опубликованным подтверждённым отзывам.
- В защищённом кабинете можно просматривать сообщения, отвечать, скрывать и восстанавливать публикации.
- Прежние отзывы и ответы сохранены без добавления выдуманных оценок.

Проверено: рабочий сайт, выбор звёзд, выбор предложения и раскрытие вопросов; серверные проверки защиты кабинета; настоящее письмо и подтверждение по ссылке. Владелец подтвердил получение технического вопроса в Telegram. Проверочное сообщение не публиковалось.

Инструкция по установке и настройке — README.md в этой папке. Служебные идентификаторы, адреса облачной консоли и параметры доступа в этом файле не хранятся.
